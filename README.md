# LuolastoGen

Tietojenkäsittelytieteen aineopintojen harjoitustyö (algoritmit ja tekoäly)

[Määrittelydokumentti](documentation/maarittely.md)

## Sovelluksen käyttö
Siirry virtuaaliympäristöön.

    eval $(poetry env activate)

Asenna riippuvuudet

    poetry install

Aja sovellus

    python3 src/main.py
